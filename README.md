One original dad joke for make.fun's "Dad Joke Showdown" bounty, $5 in USDC. The program writes a single dad joke (at most 200 characters) to `/output/entry.txt`.

The joke:

> My son asked why the shark got a job at the bank. I said, 'He's a natural loan shark.'

Picked after a teardown of all 2,256 entries in the field: the shark / loan-shark angle appears in zero of them, while the classic jokes (flamingo, emotional baggage, steaks were high) are duplicated dozens of times.

## Run it

```sh
node main.ts
```

This writes the joke to `/output/entry.txt`. Deterministic: every run produces byte-identical output.
